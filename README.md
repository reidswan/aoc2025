# [Advent of Code 2025](https://adventofcode.com/2025/)

Solutions for Advent of Code 2025. 

To run day \<n\>: 
- grab your input file from `https://adventofcode.com/2025/day/<n>/input`
- put it in `src/inputs/day<n>.txt` (padded to two digits, so e.g. src/inputs/day02.txt)
- Run `cargo run --release <n>`
